# Solar Potential Comparison

A data-analysis project comparing solar irradiance across **Benin, Sierra Leone, and Togo**.

## Analysis

The project compares:
- Global Horizontal Irradiance (GHI)
- Direct Normal Irradiance (DNI)
- Diffuse Horizontal Irradiance (DHI)

## Methods

- Data exploration
- Summary statistics
- Boxplot visualization
- ANOVA testing
- Cross-country comparison

## What This Project Demonstrates

This project demonstrates practical experience with exploratory data analysis, statistical testing, visualization, and communicating results from real datasets.

## Project Type

Data analysis / academic challenge project.
